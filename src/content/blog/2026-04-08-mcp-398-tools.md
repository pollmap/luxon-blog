## MCP란 무엇인가

Model Context Protocol(MCP)은 AI 에이전트가 외부 도구와 데이터 소스에 접근하기 위한 표준 프로토콜이다. LLM이 단순한 텍스트 생성을 넘어 <strong>실시간 데이터 조회, 계산, 시스템 제어</strong>를 수행할 수 있게 만드는 인터페이스 계층이다.

Luxon AI의 Nexus Finance MCP는 이 프로토콜 위에 <strong>398개 금융 특화 도구</strong>를 구축했다. 하나의 엔드포인트에서 한국 주식, 미국 매크로, 크립토, 대체 데이터, 밸류에이션까지 통합 접근이 가능하다.

## 398개 도구 카테고리별 분류

### 한국 시장 데이터

| 카테고리 | 도구 수 | 주요 기능 |
|----------|---------|-----------|
| KRX (한국거래소) | 38 | 종목 시세, 거래량, 업종별 지수, ETF/ETN, 공매도 잔고 |
| DART (전자공시) | 52 | 재무제표(CFS), 사업보고서, 지분공시, 임원현황, 배당 |
| KIS (한국투자증권) | 24 | 실시간 호가, 주문 실행, 잔고 조회, 체결 내역 |

KRX 38개 도구는 한국 시장의 기초 데이터를 담당한다. <strong>업종별 PER/PBR 분포, 외국인/기관 순매수, 프로그램 매매</strong> 등 시장 미시구조 분석에 필수적인 데이터를 제공한다.

DART 52개 도구는 전자공시 시스템의 거의 모든 API를 래핑한다. 연결재무제표(CFS) 전용 원칙을 적용하여, 별도재무제표(OFS)는 의도적으로 배제했다.

### 글로벌 매크로

| 카테고리 | 도구 수 | 주요 기능 |
|----------|---------|-----------|
| ECOS (한국은행) | 18 | 기준금리, CPI, GDP, M2, 경상수지, 가계부채 |
| FRED (미연준) | 24 | FFR, Treasury Yield, Breakeven Inflation, 고용지표 |

ECOS와 FRED를 결합하면 <strong>한미 금리 스프레드, 인플레이션 디커플링, 환율 드라이버 분석</strong>이 하나의 파이프라인에서 가능해진다.

### 크립토 및 대체 데이터

| 카테고리 | 도구 수 | 주요 기능 |
|----------|---------|-----------|
| 크립토 | 29 | 업비트/바이낸스 시세, 오더북, 펀딩레이트, 온체인 지표 |
| 대체 데이터 | 53 | 뉴스 센티먼트, 소셜 버즈, 특허 동향, 위성 데이터 프록시 |
| 뉴스/미디어 | 26 | 실시간 뉴스 수집, 키워드 필터링, 감성 분석 |

대체 데이터 53개 도구는 전통 금융 데이터만으로는 포착하기 어려운 신호를 잡아낸다. 뉴스 센티먼트 점수와 소셜 미디어 언급량을 정량화하여 <strong>이벤트 드리븐 전략</strong>의 입력으로 활용한다.

### 퀀트 및 분석

| 카테고리 | 도구 수 | 주요 기능 |
|----------|---------|-----------|
| 퀀트 엔진 | 38 | 팩터 분석, 백테스트, Walk-Forward, 포트폴리오 최적화 |
| 시각화 | 33 | SVG 차트, 다크테마 렌더링, 인터랙티브 그래프 |
| 밸류에이션 | 10 | DCF, DDM, Comps, Sum-of-Parts, EV/EBITDA 산출 |
| 리스크 | 15 | VaR, CVaR, 드로다운 분석, 상관행렬, 스트레스 테스트 |

밸류에이션 10개 도구는 <strong>Forward/Trailing 기준을 반드시 명시</strong>하도록 설계되었다. "PER 12배"라는 숫자만으로는 의미가 없다. 12MF Forward인지, TTM Trailing인지에 따라 해석이 완전히 달라진다.

| 카테고리 | 도구 수 | 주요 기능 |
|----------|---------|-----------|
| 파일/문서 | 18 | PDF 파싱, Excel 생성, HTML 렌더링, Vault 연동 |
| 시스템 | 12 | 헬스체크, 로그, 에이전트 간 통신, 세션 관리 |
| 외부 API | 27 | Yahoo Finance, Alpha Vantage, CoinGecko 프록시 |

## 실전 활용 사례: 현대건설 E2E 분석

398개 도구가 실제로 어떻게 연결되는지, 현대건설(000720) 기업분석 파이프라인을 예시로 보자.

<strong>Phase 1 — 데이터 수집 (12개 도구)</strong>

DART에서 최근 5개년 연결재무제표를 가져온다. 매출, 영업이익, 순이익, 자산총계, 부채비율을 추출한다. KRX에서 동종업계(건설업) 평균 PER/PBR을 조회한다.

<strong>Phase 2 — 매크로 컨텍스트 (6개 도구)</strong>

ECOS에서 건설 수주액, 주택 인허가 건수, 기준금리 추이를 수집한다. 건설업은 금리에 민감하므로 FRED의 미국 10년물 금리와 한미 스프레드도 함께 분석한다.

<strong>Phase 3 — 밸류에이션 (4개 도구)</strong>

DCF 모델과 Peer Comparison을 병렬로 실행한다. WACC 산출, 잔여이익 모델, EV/EBITDA 멀티플 비교를 통해 적정가치 범위를 도출한다.

<strong>Phase 4 — 리포트 생성 (8개 도구)</strong>

시각화 도구로 SVG 차트 25개 이상을 생성하고, HTML 리포트로 조립한다. 80,000자 이상의 보고서가 자동으로 빌드된다.

전체 파이프라인에서 <strong>30개 이상의 도구가 유기적으로 연결</strong>된다. 수작업으로는 며칠 걸릴 분석이 하나의 세션에서 완료된다.

## 공개 엔드포인트

Nexus Finance MCP는 VPS에서 운영되며, 인증된 에이전트만 접근할 수 있다.

- 헬스체크: `curl http://127.0.0.1:8100/health`
- 프로토콜: HTTP 기반 MCP (type: "http")
- 보안: nginx 인증 + IP 제한 + UFW deny + SSH key-only

현재 Luxon AI의 3개 에이전트(HERMES, NEXUS, DOGE)가 이 398개 도구를 공유하며, 각자의 역할에 맞는 도구 서브셋을 호출한다.

## 왜 398개인가

도구 수 자체가 목적은 아니다. 금융 분석의 <strong>전체 파이프라인을 빈틈 없이 커버</strong>하려면 이 정도 규모가 필요하다. 데이터 수집에서 밸류에이션까지, 한국 시장에서 글로벌 매크로까지, 전통 자산에서 크립토까지 — 하나의 프로토콜로 통합하는 것이 핵심이다.

다음 목표는 400개를 넘기는 것이 아니라, 기존 도구의 <strong>정확도와 속도를 개선</strong>하는 것이다. 도구가 많아도 신뢰할 수 없으면 의미가 없다.
