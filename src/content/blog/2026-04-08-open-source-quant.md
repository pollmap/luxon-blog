## 왜 오픈소스인가

퀀트 투자의 가장 큰 문제는 블랙박스다. Luxon AI는 다르게 접근한다: <strong>모든 것을 공개한다.</strong>

## 3가지 핵심 가치

<strong>공공성</strong> — 금융 지식은 특권이 아니다. MCP 398개 금융 도구를 무료 공개.

<strong>실용성</strong> — 이론이 아닌 실전. 실제 KIS API로 주문 실행, 실제 DART 데이터로 분석. 목업 금지.

<strong>진실성</strong> — 투명한 트랙 레코드. 매주 복기 결과를 블로그에 자동 발행. 실패도 기록.

## GitHub 4개 레포

| 레포 | 설명 |
|------|------|
| nexus-finance-mcp | 398도구 금융 MCP 서버 |
| cufa-equity-report | AI 기업분석 보고서 |
| open-trading-api | AI 퀀트 운용 시스템 (378 tests) |
| CUFA-wiki | 금융 교육 위키 + 퀀트 가이드 |

<strong>AI 퀀트는 비밀이 아니라 방법론이다.</strong> 방법론은 공유될 때 더 강해진다.
