# 거시경제 구조분석의 새로운 기준: 이질적 마르코프 전환 이분산성을 활용한 구조적 벡터자기회귀 식별 검증

## 서론: 왜 이 연구가 중요한가

거시경제 분석에서 가장 어려운 문제 중 하나는 <strong>구조적 충격(structural shock)을 식별하는 것</strong>입니다. 금리 인상이 경제에 미치는 영향, 공급 충격과 수요 충격의 상대적 크기, 금융 위기 시 신용 경색의 파급 경로—이러한 질문들에 답하려면 관측 불가능한 충격들을 데이터에서 분리해 내야 합니다. 

전통적으로 거시경제학자들은 구조적 벡터자기회귀(SVAR: Structural Vector Autoregression) 모형을 사용해왔습니다. 하지만 이 모형의 큰 약점은 <strong>모든 경제 충격이 동일한 변동성 체제를 따른다고 가정</strong>한다는 것입니다. 현실은 다릅니다. 금리 충격의 불확실성이 큰 시기가 있는가 하면, 공급 충격의 변동성이 특히 높은 국면도 있습니다.

2026년 3월 arXiv에 게시된 논문 "Identification Verification for Structural Vector Autoregressions with Sparse Heterogeneous Markov Switching Heteroskedasticity"는 이 문제에 혁신적인 해결책을 제시합니다. <strong>각 충격이 자신만의 마르코프 전환 분산 과정을 따르도록 허용</strong>하는 동시에, 식별이 정말 이루어졌는지 <strong>통계적으로 검증</strong>하는 방법을 제안하는 것입니다.

이 글에서는 이 연구의 핵심 방법론, 실무적 의미, 그리고 거래와 거시경제 분석에 어떻게 적용될 수 있는지를 상세히 설명합니다.

## 1부: 기존 SVAR 모형의 한계와 이분산성 식별의 역할

### 구조적 벡터자기회귀의 기본 원리

구조적 벡터자기회귀 모형의 핵심은 다음 식입니다:

$$B_0 \varepsilon_t = u_t$$

여기서:
- $B_0$는 구조 행렬(structural matrix)로서, 각 변수 간의 동시적 관계를 나타냅니다
- $\varepsilon_t$는 축약형(reduced-form) 오차항입니다
- $u_t$는 구조적 충격(structural shocks)으로, 경제적으로 해석 가능한 것들입니다

경제학자가 관심 있는 것은 $u_t$입니다. 예를 들어 금리 충격, 유가 충격, 신용 충격 같은 것들이죠. 하지만 우리가 데이터에서 직접 보는 것은 $\varepsilon_t$뿐입니다. 따라서 <strong>$B_0$를 식별(identify)해야만</strong> 구조적 충격을 추정할 수 있습니다.

### 동일 분산성 가정의 문제점

전통적 SVAR 분석에서는 다음과 같이 가정했습니다:

$$u_t \sim N(0, \Sigma)$$

즉, 모든 충격이 <strong>시간 불변의</strong> 공분산 행렬 $\Sigma$를 가진다는 뜻입니다. 이 가정 하에서, 만약 한 충격의 분산이 특정 시점에서 갑자기 증가하면, 그것이 다른 충격과 구별되는 특성이 됩니다. 이를 <strong>이분산성을 통한 식별(identification through heteroskedasticity)</strong>이라 부릅니다.

하지만 이 접근법은 <strong>모든 충격이 같은 변동성 체제를 공유한다</strong>고 암묵적으로 가정합니다. 예를 들어:
- 만약 시장이 불황 체제로 진입하면, 모든 거시경제 충격의 불확실성이 동시에 증가합니다고 봅니다
- 특정 정책 불확실성(예: 금융규제 개편)은 금리 충격의 분산만 높일 수 있다는 점을 간과합니다
- 공급 부족(예: 반도체 부족)과 수요 충격이 시간을 달리하여 변동성이 높아질 수 있다는 현실을 포착하지 못합니다

## 2부: 이질적 마르코프 전환 이분산성 모형의 혁신

### 핵심 아이디어: 충격별 독립적 변동성 과정

본 연구의 획기적 기여는 다음과 같습니다:

$$u_{n,t} \mid s_{n,t} \sim N(0, \sigma^2_{n,s_{n,t}})$$

여기서:
- $n$은 충격의 인덱스(예: $n=1$은 금리 충격, $n=2$는 공급 충격)
- $s_{n,t}$는 <strong>충격 $n$만의 마르코프 상태</strong>(regime state)
- $\sigma^2_{n,s_{n,t}}$는 시간과 충격과 상태에 따라 달라지는 분산

이것이 무엇을 의미하는지 구체적으로 설명하겠습니다.

### 구체적 사례: 통화정책 충격과 공급 충격

기준금리 결정회의가 있는 분기($t=t_0$)를 생각해봅시다:
- <strong>통화정책 충격</strong>은 의외성이 높아 표준편차가 평소의 2배 증가합니다 ($\sigma_{rate,s=high}$)
- 그러나 동시에 석유 시장은 조용하고, <strong>공급 충격</strong>의 분산은 여전히 낮습니다 ($\sigma_{supply,s=low}$)
- 전통 SVAR는 이런 비대칭성을 포착하지 못하고, 하나의 공통 "불황 상태"로 모든 것을 압축합니다

본 연구가 제안하는 모형에서는 각 충격이 <strong>자신의 상태 과정</strong> $s_{n,t}$를 가지므로, 정책 결정의 불확실성과 공급망 안정성이 동시에 높을 수도, 반대로 한쪽은 높고 다른 쪽은 낮을 수도 있습니다.

### 정규화: 작은 디테일, 큰 효과

여기서 중요한 기술적 디테일이 있습니다:

$$\frac{1}{M_n} \sum_{m=1}^{M_n} \sigma^2_{n,m} = 1$$

이것은 정규화(normalization) 제약입니다. 각 충격 $n$에 대해, 모든 가능한 상태 $m$에서의 분산들의 평균이 1이 되도록 정합니다.

<strong>왜 이것이 중요한가?</strong>

구조적 벡터자기회귀에서는 $B_0$의 크기와 $u_t$의 분산이 <strong>곱셈적으로 얽혀</strong> 있습니다. $B_0$를 2배로 크게 설정하고 충격의 분산을 절반으로 줄이면, 최종 결과는 같습니다. 따라서 정규화 제약 없이는 모형이 식별되지 않습니다(under-identified).

본 연구의 정규화 방식은 각 충격의 <strong>평균 분산을 고정</strong>함으로써, $B_0$의 크기와 충격-특이적 변동성 상태들을 유일하게 결정합니다. 이는 <strong>추정 정확도 개선</strong>과 <strong>예측 품질 향상</strong>으로 직결됩니다.

## 3부: 식별 검증의 통계적 방법론

### 기존 접근법의 문제점

많은 거시경제 연구자들이 이분산성을 사용한 식별을 다음과 같이 취급했습니다:

> "데이터를 보니 특정 기간에 변동성이 높으니, 이것이 한 충격을 식별한다고 <strong>가정하자</strong>"

이것은 매우 위험합니다. 왜냐하면:
1. <strong>확인 편향(confirmation bias)</strong>: 원하는 충격의 분산 패턴을 찾으면, 그것이 정말로 해당 충격에 의한 것인지 검증하지 않습니다
2. <strong>약한 식별(weak identification)</strong>: 두 충격의 분산 변화 패턴이 매우 유사하면, 통계적으로 구별할 수 없습니다
3. <strong>구조적 변화(structural breaks)</strong>: 모형의 기본 구조가 바뀌는데도 식별 변동성만 탓합니다

### 본 연구의 해결책: 식별을 검증 가능한 주장으로

본 논문의 핵심 방법론은 다음과 같습니다:

<strong>Step 1: 이질적 마르코프 전환 분산을 가정하지 않고 추정</strong>

먼저 각 충격이 <strong>동일 분산(homoskedastic)</strong>이라고 가정한 "제약 모형"을 추정합니다.

<strong>Step 2: 이질적 마르코프 전환 분산을 허용하여 추정</strong>

이제 각 충격이 자신의 마르코프 상태를 가질 수 있도록 확장합니다. 이것이 "제약 해제 모형"입니다.

<strong>Step 3: 베이즈 팩터로 비교</strong>

두 모형의 주변 우도(marginal likelihood)를 비교합니다. 베이즈 팩터는 다음과 같습니다:

$$BF = \frac{p(y \mid \text{heteroskedastic model})}{p(y \mid \text{homoskedastic model})}$$

- $BF > 10$: 강한 증거로 이분산성 모형 지지
- $1 < BF < 10$: 약한 증거
- $BF < 1$: 오히려 동일 분산성 모형이 더 나음

이 방식은 <strong>식별을 통계적으로 테스트 가능한 주장</strong>으로 변환합니다.

### 실무적 의미

예를 들어 암호화폐와 거시경제의 전염 채널을 분석한다면:
- "금리 충격이 비트코인을 움직인다"고 주장하기 전에, 금리 충격의 분산이 정말로 비트코인의 변동성 변화를 설명하는지 베이즈 팩터로 확인
- 만약 베이즈 팩터가 10 미만이면, 다른 식별 전략(예: 외생성 가정, 신문 기반 충격)을 찾아야 함을 의미

## 4부: 희소 과적합 체제(Sparse Over-Specified Regimes)

### 전통적 문제: 체제 개수를 어떻게 정할 것인가?

마르코프 전환 모형을 사용할 때, 연구자는 먼저 <strong>몇 개의 상태(regime)가 존재하는지 결정</strong>해야 합니다:
- 불황과 호황: 2개 상태
- 불황, 정상, 호황: 3개 상태?
- 혹은 4개, 5개?

이것을 잘못 설정하면:
- 너무 적으면(under-specified): 실제 복잡성을 놓침
- 너무 많으면(over-specified): 과적합되어 표본 외 예측이 형편없음

### 본 연구의 혁신: 희소성으로 자동 선택

본 논문은 이를 다르게 접근합니다:

> <strong>필요한 것보다 더 많은 상태를 허용하되, 사용되지 않는 상태는 자동으로 확률이 0에 수렴하도록 한다</strong>

예를 들어:
- 충격 $n$에 대해 $M_n = 5$개 상태를 허용
- 추정 결과, 3개 상태만 실제로 사용됨 (나머지는 확률이 무시할 수준)
- 이렇게 되면 자동으로 3개 상태 모형이 선택됨

이것의 장점은:
1. <strong>유연성</strong>: 다양한 가능성을 탐색
2. <strong>견고성</strong>: 특정 상태 개수에 고정되지 않음
3. <strong>해석 가능성</strong>: 최종 모형은 간단하지만, 수렴 과정에서 복잡성 포착

### 기술적 구현

이는 보통 <strong>다이리클레 과정(Dirichlet process)</strong> 또는 <strong>인도 뷔페 과정(Indian buffet process)</strong> 같은 베이지안 비모수 방법으로 구현됩니다. 과도한 상태에 대해 희소성(sparsity) 제약을 부과하여, 불필요한 매개변수가 데이터 없이도 자동으로 "사라지게" 합니다.

## 5부: 실무 예제와 주의사항

### 실무 적용 체크리스트

본 논문은 다음과 같은 주의를 강조합니다:

| 위험 요소 | 대응 방법 |
|---------|---------|
| 체제 오분류(Regime misclassification) | 베이즈 필터를 이용해 각 시점의 상태 확률을 점검 |
| 약한 분산 분리(Weak variance separation) | 상태 간 분산 비율이 1.1 이상인지 확인 |
| 구조적 변화(Structural breaks) | 표본 기간을 이동 창으로 나누어 결과 비교 |
| 선행 민감성(Prior sensitivity) | 디리클레 선행의 농도(concentration) 모수 변화 시 결과 확인 |
| 모형-표본 불균형 | 변수 개수 vs 표본 길이 비율이 1:100 이상이 되도록 |

### ORACLE의 구체적 활용 사례

본 논문은 다음과 같은 구체적 응용을 제시합니다:

<strong>거시-암호자산 전염 분석:</strong>

기준금리, 달러 유동성, 인플레이션 깜짝(surprise), 신용 스프레드 충격이 비트코인과 이더리움에 미치는 인과적 영향을 분석할 때:

1. 6변수 SVAR 구축: 연방기금 금리 | 달러 인덱스 | 인플레이션 | 신용 스프레드 | BTC 가격 | ETH 가격

2. 각 충격별 마르코프 전환 분산 허용

3. 베이즈 팩터를 통해 각 거시 충격이 정말로 암호자산 변동성을 설명하는지 검증

4. 확인된 충격만 사용하여 임펄스 반응 함수(IRF) 추정

5. 안정화자산(예: USDC, USDT) 프리미엄 변화를 이 IRF로 설명

이렇게 하면 "정책 금리가 비트코인을 움직인다"는 주장이 단순한 상관성이 아니라 <strong>통계적으로 검증된 인과관계</strong>가 됩니다.

### 추정 결과 스트레스 테스트

본 논문은 어떤 이분산성 식별 결과도 다음과 같이 검증할 것을 권장합니다:

- <strong>시차 길이 변화</strong>: 시차가 2에서 6으로 변할 때 임펄스 반응이 안정적인가?
- <strong>변수 집합 변화</strong>: 변수를 추가하거나 제거해도 결론이 같은가?
- <strong>표본 기간 변화</strong>: 2015-2020 vs 2020-2026에서 다른 결과가 나오나?
- <strong>대안적 변동성 명세</strong>: 마르코프 전환 대신 확률적 변동성(SV) 모형을 쓸 때는?

이 모든 검사를 통과해야만 "견고한" 인과관계로 판단할 수 있습니다.

## 6부: 기술적 심화: 정규화와 식별의 상호작용

### 곱셈적 얽힘의 본질

구조적 벡터자기회귀의 매개변수화 문제를 더 깊이 이해하기 위해, 축약형(reduced form)과 구조형(structural form)의 관계를 다시 봅시다:

$$A_p y_t = u_t + \Sigma_p A_{p,j} y_{t-j}$$

이를 정렬하면:
$$\Sigma_t = B_0^{-1} \Omega_t (B_0^{-1})^\top$$

여기서 $\Omega_t$는 구조적 충격의 공분산 행렬입니다.

이분산 설정에서:
$$\Omega_t = \text{diag}(\sigma^2_{1,t}, \sigma^2_{2,t}, \ldots, \sigma^2_{n,t})$$

<strong>문제</strong>: 임의의 스칼라 $\lambda$에 대해, $B_0 \to \lambda B_0$이고 $\sigma^2_{n,t} \to \lambda^{-2} \sigma^2_{n,t}$로 설정해도 $\Sigma_t$는 변하지 않습니다. 즉, 축약형 우도는 동일합니다.

<strong>해결</strong>: 정규화 제약 $\frac{1}{M_n}\sum_m \sigma^2_{n,m}=1$을 부과하면, 이 곱셈적 자유도가 제거되고 $B_0$와 $\{\sigma^2_{n,m}\}_{m,n}$이 유일하게 결정됩니다.

### 정규화의 추정 정확도에 대한 영향

좋은 정규화는:
1. <strong>피셔 정보 행렬(Fisher Information Matrix)의 조건수(condition number)를 개선</strong> → 추정 분산 감소
2. <strong>최적화 수렴 속도 가속화</strong> → 계산 시간 단축
3. <strong>사후 분포(posterior distribution)의 집중도 증가</strong> → 신뢰 구간 축소

반대로 부적절한 정규화는 수치 불안정성을 초래하여, 같은 데이터에서도 다른 추정값을 얻을 수 있습니다.
